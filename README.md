# Gestion-tienda-tecnologica
La tienda TechZone es un negocio dedicado a la venta de productos tecnológicos, desde laptops y teléfonos hasta accesorios y componentes electrónicos. Con el crecimiento del comercio digital y la alta demanda de dispositivos electrónicos, la empresa ha notado la necesidad de mejorar la gestión de su inventario y ventas. 

- schema.sql: contiene todos el scirpt sql para crear  todas las tablas. Uso de claves primarias y foráneas para asegurar integridad referencial contiene de restricciones (NOT NULL, CHECK, UNIQUE).

- datasets.sql: posee unos 15 registros de cada tabla para insertar datos sinteticos de pueba.

- Consultas SQL (queries.sql): Incluye 6 consultas avanzadas.
